# Teoria do Direito Privado

Material de estudo de Direito Civil I (Teoria do Direito Privado) para o bacharelado em Direito: introdução e codificação, pessoa natural e capacidade, direitos da personalidade, início e fim da personalidade, domicílio e bens jurídicos. Inclui glossário com busca e simulado com 81 questões comentadas.

Página única (`index.html`), sem dependências de build. Para publicar no GitHub Pages: envie `index.html` para a raiz do repositório e ative *Settings → Pages → Deploy from a branch → main / (root)*.

## Fontes
Código Civil (Lei 10.406/2002), Constituição Federal de 1988, CPC/2015 (Lei 13.105/2015), Lei de Registros Públicos (Lei 6.015/1973), Estatuto da Pessoa com Deficiência (Lei 13.146/2015), Lei 11.804/2008, Lei 15.139/2025 e jurisprudência do STF e do STJ, conferidos nos sites oficiais.
